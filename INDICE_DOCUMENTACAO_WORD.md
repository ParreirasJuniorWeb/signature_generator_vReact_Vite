## 🔄 Atualização dos Documentos

### Scripts Disponíveis
1. `create_word_docs.py` - Gera documentos individuais de teste
2. `create_docs_word.py` - Gera documentos técnicos individuais
3. `create_consolidated_doc.py` - Gera documento consolidado de testes
4. `create_docs_consolidated.py` - Gera documento técnico consolidado

```bash
# Documentos de teste
python create_word_docs.py

python create_docs_word.py

# Consolidados
python create_consolidated_doc.py
python create_docs_consolidated.py
```
